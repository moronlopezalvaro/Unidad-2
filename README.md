# 2.2.-Actividad-El-Dilema-del-Arquitecto-Frontend

## Descripción de la actividad
En esta práctica se plantean varios escenarios reales de desarrollo frontend y se analiza qué tecnología es la más adecuada para cada caso. La finalidad es comprender cómo elegir la herramienta correcta según el tipo de aplicación, su complejidad y sus necesidades de rendimiento.
